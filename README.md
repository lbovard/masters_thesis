Code
====

The code behind the thesis lives in `code/`, merged in with full history from
the original repositories:

- `code/linear-stability-boussinesq-2d/`: Fortran solver for the linear first-order Boussinesq equations (stability of a vortex pair)
- `code/linear_stab_plots/`: plotting scripts for the linear stability results
- `code/matlab_NS_solvers/`: old MATLAB research code, chiefly a 2D Navier-Stokes solver in the vorticity formulation
- `code/spectral_thesis/`: spectral-methods tests used for the thesis
